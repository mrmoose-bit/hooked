# Hooked

How scam texts get you, told as an interactive 3D story, with a small neural network
that runs in the visitor's browser. One static page (`index.html`): no server, no API key, no cost.

## Put it online (no terminal)

1. On github.com, create a new repository (for example `hooked`).
2. Click "uploading an existing file", drag in `index.html`, and click "Commit changes".
3. On vercel.com, click "Add New…" then "Project", import the repository,
   leave the framework preset as "Other", and click "Deploy".

To update the site later, upload a new `index.html` to the repository; Vercel redeploys on its own.
